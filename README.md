ScanQ is an ultra-fast, lightweight, cross-platform Flutter application designed for scanning and generating QR codes and barcodes. Built with a privacy-first approach, it works fully offline without accounts, tracking, or ads.

---

## ⚡ Highlights

* **Instant Scanning:** 60 FPS real-time barcode and QR recognition powered by Google ML Kit.
* **16+ Supported Formats:** QR Code, Data Matrix, Aztec, PDF417, EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, Codabar, ITF, and more.
* **Pure Hardware Zoom:** Smooth 1x to 4x camera sensor zoom without visual canvas distortion.
* **Custom QR Generator:** Create codes for Plain Text, URLs, Wi‑Fi networks, Contacts (vCard), Phone Numbers, SMS, Emails, and Geolocation.
* **Local History & Favorites:** Easily access, filter, copy, share, or delete past scans.
* **Multi-Language Interface:** Full native support for English and Bengali (বাংলা).
* **Smart Actions:** Direct one-tap Wi‑Fi connection, direct calling, email composing, and URL opening with safety warnings.
* **Privacy-First & Offline:** No accounts, no backend tracking database, and no intrusive ads. All scan data stays on your device.

## 🛠️ Tech Stack

* **Framework:** [Flutter](https://flutter.dev) (Dart SDK 3.9+)
* **Scanner Core:** MobileScanner & Google ML Kit Barcode Scanning
* **State & Persistence:** SharedPreferences & Local SQLite Storage
* **Push Notifications:** Firebase Cloud Messaging (FCM)
* **Audio Feedback:** AudioPlayers (Low-latency sound effects)
